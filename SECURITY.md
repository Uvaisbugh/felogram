# Security policy

This is an early alpha; use the latest revision. Older releases have no maintenance commitment.

Never post API hashes, login codes, passwords, sessions, or private messages in issues or logs. Use GitHub private vulnerability reporting once enabled. If unavailable, request a private contact without disclosing exploit details. The owner must enable private reporting before announcing a release.

Session keys use Windows DPAPI. Snippets remain local until copied; system clipboard history and clipboard applications may retain copied text. Felogram never executes pasted code.
